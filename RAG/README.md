# Banking Chatbot with RAG and LangChain

Welcome to the **Banking Chatbot**! This project leverages **Retrieval-Augmented Generation (RAG)** and **LangChain** to create an intelligent chatbot capable of answering banking-related questions. The chatbot uses **Llama 2** as the language model and **FAISS** for efficient document retrieval.

![chat_bot UI](https://github.com/pipe1223/deepFraud/blob/master/RAG/images/sample_interface.png) 

---

## **Features**
- **Retrieval-Augmented Generation (RAG)**: Combines retrieval and generation to provide accurate and context-aware responses.
- **Multi-Chat Support**: Create and switch between multiple chat sessions.
- **Feedback Mechanism**: Users can provide feedback on responses (thumbs up/down).
- **Download Chat History**: Export chat history as a text file.

---

## **Technologies Used**
- **LangChain**: Framework for building applications with language models.
- **Llama 2**: Open-source language model for response generation.
- **FAISS**: Vector database for efficient document retrieval.
